# Smart Crop Recommendation and Soil Identification System 🌱

A Machine Learning and Deep Learning based web application that recommends suitable crops based on soil and environmental parameters and identifies soil types from uploaded images.

## 🚀 Live Demo
[Click here to use the application](https://smart-crop-recommendation-system-r2fkmtzkdamxsugogjpgsd.streamlit.app)

## ✨ Features

### 1. Crop Recommendation
- Recommends suitable crops using soil and environmental parameters.
- Uses a Random Forest Classifier.
- Inputs include:
  - Nitrogen (N)
  - Phosphorus (P)
  - Potassium (K)
  - Temperature
  - Humidity
  - Soil pH
  - Rainfall

### 2. Soil Type Identification
- Identifies soil types from uploaded images.
- Uses MobileNetV2 transfer learning.
- Supports four soil categories:
  - Alluvial Soil
  - Black Soil
  - Clay Soil
  - Red Soil

### 3. Crop and Soil Compatibility
- Displays an advisory about crop and soil compatibility.
- Uses rule-based recommendations.

## 💻 Run Locally

1. Clone the repository:

   `git clone https://github.com/sakshi029580-cmd/smart-crop-recommendation-system.git`

2. Open the project folder:

   `cd smart-crop-recommendation-system`

3. Install dependencies:

   `pip install -r requirements.txt`

4. Run the application:

   `streamlit run app.py`
